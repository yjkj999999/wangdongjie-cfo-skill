## 四、图表注记惯例（「贝莱德语法」，可复用判定标准）

1. **估计段**：预测区上方置「估计」二字标签；区段用浅色调或虚线边界。
2. **免责前缀三态**（置于资料来源行首）：`前瞻性估计可能不会实现` / `所示数据仅代表过往表现` / `仅供说明`。
3. **资料来源固定句式**：`资料来源：贝莱德智库、[机构]，数据来自 [Haver Analytics | LSEG Datastream | 彭博 | PitchBook | Preqin | CBO | 美联储 | Dealogic | Aladdin]，[YYYY年M月]。`
4. **注释固定句式**：`注：图中线条/柱状图呈列的是…`（含口径、指数代理、修正说明）。
5. **图例**置面板顶部横排；轴单位随轴竖排（千人 / 年率 / 基点 / 十亿美元 / 万亿美元 / 百分点）。
6. **基准=100 惯例**：指数化比较注明基准时点（`2023年1月 = 100`、`2016年8月 = 100`）。
7. **符号语义**：空心柱 = 假设值；虚线 = 估计/阈值；浅色带 = 分位区间；实心点 = 现配置，空心点 = 早期观点。
8. **量尺三态**：低配 / 中性 / 超配 + 空心「早期观点」标记（p17/p19/p20）。
9. **信号徽章两态**：乐观（实底）/ 观察中（描边）（p8）。
10. **双语对照**：资产地图节点中英并列（p18）。
