二、快速开始（3 步上线）

第 1 步：一键安装

# 进入 Skill 目录
cd super-stock-trading-skill

# 运行安装脚本（自动安装 16 个 GitHub Skills + Wind Skills + Python 依赖）
./scripts/install.sh

# 或非交互模式
./scripts/install.sh --non-interactive

第 2 步：配置 API Key

# 复制配置模板
cp assets/config_template.env ~/.stock_skill.env

# 编辑填入你的 Key
vi ~/.stock_skill.env
# WIND_API_KEY=ak_xxx        → https://aifinmarket.wind.com.cn 获取
# TUSHARE_TOKEN=xxx          → https://tushare.pro 获取
# GITHUB_TOKEN=ghp_xxx       → https://github.com/settings/tokens 获取
# CLAWHUB_TOKEN=xxx          → clawhub login 获取

# 加载配置
source ~/.stock_skill.env

第 3 步：开始操盘

# 盘前分析（7:00-9:15）
python3 scripts/daily_pipeline.py --phase morning

# 盘后复盘（15:00 后）
python3 scripts/daily_pipeline.py --phase evening

# 分析特定股票
python3 scripts/daily_pipeline.py --phase morning --stock 600519

# 周末深度研究
python3 scripts/daily_pipeline.py --phase weekly

# 月度组合管理
python3 scripts/daily_pipeline.py --phase monthly

定时自动化（crontab）

# 盘前简报（每个交易日 7:30）
30 7 * * 1-5  cd ~/super-stock-trading-skill && python3 scripts/daily_pipeline.py --phase morning >> reports/morning.log 2>&1

# 盘后复盘（每个交易日 15:30）
30 15 * * 1-5  cd ~/super-stock-trading-skill && python3 scripts/daily_pipeline.py --phase evening >> reports/evening.log 2>&1

# 周末深度研究（每周六 9:00）
0 9 * * 6  cd ~/super-stock-trading-skill && python3 scripts/daily_pipeline.py --phase weekly >> reports/weekly.log 2>&1

五、全球财富报告资源（3 份）

内置 3 份权威机构 2026 年财富报告，为宏观资产配置和"年度 10 亿收入跃迁"目标提供顶层视野。Agent 在用户询问全球财富、资产配置方向等问题时自动引用。

1. 莱坊 2026 财富报告（Knight Frank）

核心主题：财富增长 · 全球地产投资 · 奢侈品收藏

全球超高净值人群（UHNWI）分布与增长趋势、优质地产投资前景、奢侈品投资品指数（名表/艺术品/红酒/老爷车）、财富态度调查。

操盘指导：地产与股市跷跷板效应 · 奢侈品/消费板块选股 · 高净值客户行为对市场风格的影响

2. 瑞银 2026 全球财富报告（UBS）

核心主题：全球财富分布 · 财富不平等 · 代际传承

全球家庭财富总量与分布（按地区/收入分层）、成年人均财富变化趋势、财富中位数与均值差距、财富不平等指数演变、未来 5 年展望。

操盘指导：全球财富增长引擎识别 · 财富分配变化对消费结构的影响 · 代际传承对家族办公室配置偏好启示

3. BCG 2026 全球财富报告 — 大重构（第 26 版）

核心主题：金融财富大洗牌 · 新兴市场 · 代际传承 · AI 与财富管理

2025 年全球金融财富达 333 万亿美元（增长 10.7%）、净财富 550 万亿美元、股票资产飙升 13.2%、黄金涨幅约 44%。预计到 2030 年以 7% CAGR 增长。四大维度：地理集中化、新兴市场（印度/巴西/墨西哥）、代际传承、AI 重塑财富管理。

操盘指导：大类资产配置方向 · 黄金避险配置 · 出海链/新兴市场投资 · 金融科技板块逻辑 · 家族办公室长期价值偏好

六、7 条内嵌风控规则

规则触发条件执行动作级别
单只止损个股亏损 ≥ -5%自动提醒止损 + 撤退方案WARN
组合止损组合总回撤 ≥ -8%强制减仓 + 暂停新建仓BLOCK
仓位上限单只仓位 > 30%提醒减仓WARN
行业集中单行业 > 40%提醒分散WARN
情绪极端温度计 ≥ 90 或 ≤ 10逆向操作提醒WARN
连续亏损连续亏损 3 次暂停交易 1 周BLOCK
杠杆禁用检测到杠杆意图拒绝执行 + 警告BLOCK
