# 伍朝辉起涨点技术体系 / Wu Zhaohui Breakout Point Technical System

## 一、起涨点定义 / Breakout Point Definition

起涨点是指个股在阶段性低位经过充分调整整理后，于当天正式放量展开上涨的临界点。

**核心特征 / Core Features：**
- 当天均线系统形成金叉
- 构成多头趋势形态
- 以阳K线或黑太阳K线报收

**定律 / Law：**
K线调整时间周期越长，起涨后的涨幅通常越大。

---

## 二、精准操盘均线系统 / Precision Moving Average System

**四线法则（不可修改参数）：**

| 均线 | 名称 | 作用 |
|---|---|---|
| 5日均线 | 攻击线 | 短期攻击趋势，判断即时买卖点 |
| 10日均线 | 操盘线 | 波段操盘趋势，判断波段持续性 |
| 30日均线 | 生命线 | 中期生命趋势，判断主升/反弹性质 |
| 60日均线 | 决策线 | 长期决策趋势，判断大方向多空 |

---

## 三、起涨点分类 / Breakout Point Classification

### 3.1 主升型起涨点 / Main-Trend Breakout

**均线特征：**
- 生命线（30日）与决策线（60日）金叉运行
- 股价在两线之上起涨

**操盘意图：**
- 主力主升拉高或滚动操盘
- 是进入波段行情的重要标志

**涨幅测算：**
- 普通行情 = 开盘价 × 0.5 + 开盘价
- 强势行情 = 开盘价 × 0.618 或 1.00 + 开盘价

### 3.2 反弹型起涨点 / Rebound Breakout

**均线特征：**
- 生命线（30日）与决策线（60日）死叉向下
- 股价在两线之下起涨

**操盘意图：**
- 主力拉高建仓为主

**涨幅测算：**
- 按普通行情 0.5倍 测算

## 四、起涨点力度强弱研判 / Breakout Strength Assessment

### 4.1 强力型起涨点 / Strong Breakout

**标准：**
- K线实体涨幅与振幅均达5%以上
- 换手率：大盘股5%以上，中小盘股10%以上
- 若成交量与K线涨幅均达标准，主升型上升强度按0.618倍计算

### 4.2 普通型起涨点 / Normal Breakout

**标准：**
- K线实体涨幅与振幅均达3%以上
- 换手率：大盘股3%左右，中小盘股5%左右
- 上升强度按0.5倍计算

### 4.3 流通盘换手参考 / Turnover Reference by Float Size

| 流通盘规模 | 合适换手率 | 警惕阈值 |
|---|---|---|
| 1亿以内小盘股 | 20%左右 | >30% |
| 2-5亿中盘股 | 10%-20% | - |
| 5-9亿大盘股 | 8%-15% | - |

## 五、四大技术修正维度 / Four Technical Correction Dimensions

交叉验证，成功率可达90%以上。

### 5.1 K线系统修正 / K-Line System Correction

- 上影线长度幅度未超越3%的属合理范围，涨势确立
- 大阳线/中阳线收盘时需突破关键阻力（决策线、生命线或底部平台）

### 5.2 量能系统修正 / Volume System Correction

- 量柱明显放大（大于昨日量一倍以上）
- 5日均量线向上拐头并穿越30日均量线
- 换手率：中小盘股5%以上，大盘股3%以上

### 5.3 MACD指标修正 / MACD Indicator Correction

- 起涨当天MACD绿柱逐步收缩，红柱出现
- DIF与DEA在0值之上或之下形成金叉
- 只要MACD红色能量柱呈正数增加状态，就应积极做多买进

### 5.4 盘口特征修正 / Order Book Feature Correction

- 起涨当天需观察攻击波（长波/中波/短波）与量峰的配合
- 标准攻击波且配合健康量峰 = 标准买进信号
- 五档买一位置出现大封单，买盘力度较强 = 跟风盘热情激发

## 六、操盘买卖法则 / Trading Rules

### 6.1 买入时机 / Buy Timing

- 次日开盘回调时逢低买进
- 或在盘中每一波量峰从大至小开始萎缩时，于均价线附近积极买入

### 6.2 持仓原则 / Position Holding Principle

- 股价还在上涨中且未出现见顶迹象时，继续保留部分仓位
- 不急于锁定利润

---

## 七、主力试盘四法 / Four Market-Maker Test Methods

起涨前兆。

### 7.1 涨停试盘 / Limit-Up Test

- 测试抛压与筹码稳定度
- 试盘后常伴随打压诱空

### 7.2 长上影线试盘 / Long Upper Shadow Test

- 盘中放量冲高后回头波调整
- 测试盘中抛压力度

### 7.3 长下影线试盘 / Long Lower Shadow Test

- 盘中打压后快速回升
- 测试下方支撑力度

### 7.4 打压挖坑试盘 / Suppression Pit Test

- 故意跌破支撑挖坑
- 坑底成交量萎缩至地量
- 股价不再下跌且量能再次放大时试盘结束

## 八、斐波那契目标测算系统 / Fibonacci Target Calculation System

以起涨点当天开盘价为基准，按斐波那契关键比例计算波段目标价位。

| 目标位 | 比例 | 计算公式 | 含义 |
|---|---|---|---|
| T1 | 0.382 | 开盘价 × 1.382 | 保守目标，反弹型普通力度 |
| T2 | 0.500 | 开盘价 × 1.500 | 普通行情标准目标 |
| T3 | 0.618 | 开盘价 × 1.618 | 强势行情目标，主升型强力起涨 |
| T4 | 1.000 | 开盘价 × 2.000 | 超强主升浪目标 |
| T5 | 1.382 | 开盘价 × 2.382 | 主升浪延伸目标 |
| T6 | 1.618 | 开盘价 × 2.618 | 极端强势行情极限目标 |

### 止盈策略 / Take-Profit Strategy

- 到达T2(0.5)减仓1/3
- T3(0.618)减仓1/3
- T4(1.0)清仓

### 止损纪律 / Stop-Loss Discipline

- 跌破起涨点当天开盘价-3%
- 或跌破生命线（30日线）
- 无条件止损

## 九、技术指标计算公式 / Technical Indicator Formulas

### 9.1 移动平均线 / Moving Average

```
MA(N) = (C1 + C2 + ... + CN) / N
```
其中 C 为收盘价，N 为周期天数。

### 9.2 MACD / Moving Average Convergence Divergence

```
EMA12 = 前一日EMA12 × 11/13 + 今日收盘价 × 2/13
EMA26 = 前一日EMA26 × 25/27 + 今日收盘价 × 2/27
DIF = EMA12 - EMA26
DEA = 前一日DEA × 8/10 + 今日DIF × 2/10
MACD柱 = (DIF - DEA) × 2
```

### 9.3 换手率 / Turnover Rate

```
换手率 = 成交量 / 流通股本 × 100%
```

### 9.4 量比 / Volume Ratio

```
量比 = 当日成交量 / (过去5日平均每分钟成交量 × 当日累计开市时间)
```

## 十一、常见技术形态 / Common Technical Patterns

### 11.1 底部形态 / Bottom Patterns

- **双底（W底）**：两个低点相近，颈线突破确认
- **头肩底**：左肩、头部、右肩，颈线突破确认
- **圆弧底**：缓慢筑底，量能逐步放大
- **V型反转**：快速下跌后快速拉升

### 11.2 持续形态 / Continuation Patterns

- **上升三角形**：底部抬高，顶部水平，向上突破
- **下降三角形**：顶部降低，底部水平，向下突破
- **旗形**：快速拉升后小幅整理，继续向上
- **楔形**：收敛整理，选择方向突破

### 11.3 顶部形态 / Top Patterns

- **双顶（M头）**：两个高点相近，颈线跌破确认
- **头肩顶**：左肩、头部、右肩，颈线跌破确认
- **圆弧顶**：缓慢筑顶，量能逐步萎缩
- **倒V型反转**：快速上涨后快速下跌

## 十二、量价关系 / Volume-Price Relationship

| 量价关系 | 含义 | 操作建议 |
|---|---|---|
| 量增价升 | 健康上涨，多头强势 | 持有/加仓 |
| 量增价平 | 多空分歧，可能变盘 | 谨慎观察 |
| 量增价跌 | 抛压沉重，空头强势 | 减仓/止损 |
| 量缩价升 | 上涨乏力，可能见顶 | 谨慎持有 |
| 量缩价平 | 整理蓄势，方向不明 | 观望 |
| 量缩价跌 | 下跌中继，或缩量见底 | 观望/等待 |
| 天量天价 | 顶部信号，主力出货 | 减仓/清仓 |
| 地量地价 | 底部信号，可能反转 | 关注/分批建仓 |
