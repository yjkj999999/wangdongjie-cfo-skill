# 报告结构模板 / Report Structure Template

## 1. 封面 / Cover Page

**内容：**
- 公司名称（英文 + 中文）
- 股票代码 + 交易所
- 报告类型：Investment Research Report / 投资研究报告
- 报告日期
- 评级（如有）
- 持仓信息（如用户提供）：买入价、持股数量、持仓市值
- 摩根士丹利风格页眉页脚

**双语示例：**
```
COFCO CAPITAL HOLDINGS CO., LTD.
中粮资本控股股份有限公司
002423.SZ | Shenzhen Stock Exchange

Investment Research Report
投资研究报告

Date: August 25, 2026
日期：2026年8月25日

Position: 8,000,000 shares @ ¥9.61
持仓：800万股 @ 9.61元
```

---

## 2. 目录 / Table of Contents

列出所有章节及页码。

---

## 3. 执行摘要 / Executive Summary

**内容（≤5行可审计摘要）：**
1. 直接结论或条件式结论
2. 支撑结论的最强单条证据及来源等级
3. 最大的未知项
4. 证据强度：一手充分 / 部分一手 / 仅二手待核
5. 一条会推翻结论的信号

**核心投资论点 / Core Investment Thesis：**
- 多头逻辑（Bull Case）：3-5条
- 空头逻辑（Bear Case）：3-5条
- 关键指标表：收盘价、总市值、PE(TTM)、PB、52周高低价

---

## 4. 持仓概览 / Position Overview

*仅在用户提供持仓信息时包含此章节*

**内容：**
- 持仓基本信息表：股票名称、代码、买入价、持股数量、持仓市值、占总股本比例
- 当前盈亏：浮动盈亏金额、浮动盈亏比例
- 关键价位表：买入价、当前价、止损价、T1-T6目标价
- 持仓盈亏敏感性分析：不同股价下的盈亏金额（对应图表5）

---

## 5. 公司概况 / Company Profile

**内容：**
- 基本信息表：
  - 公司名称（中英文）
  - 股票代码、交易所
  - 所属行业（申万一级/二级）
  - 成立日期、上市日期
  - 总股本、流通股本
  - 总市值、流通市值
  - 控股股东、持股比例
  - 实际控制人
  - 董事长、总经理
- 业务版图 / Business Map：核心业务板块及子公司
- 商业模式 / Business Model：盈利模式、收入来源、核心竞争力
- 发展历程 / Development History：关键里程碑

---

## 6. 行业分析 / Industry Analysis

**内容：**
- 行业定义与规模 / Industry Definition & Size
- 行业格局 / Industry Landscape：市场份额、竞争格局、CR5/CR10
- 同业可比公司 / Peer Comparable Companies：列表及关键指标对比表
- 行业政策 / Industry Policies：最新政策及影响
- 核心矛盾 / Core Contradictions：行业当前面临的主要问题和机遇
- 行业周期判断 / Industry Cycle Assessment：处于周期哪个阶段

---

## 7. 财务分析 / Financial Analysis

**内容：**
- 核心财务指标表 / Key Financial Metrics：
  - 近3年+最新一期：营收、营收增速、归母净利润、净利润增速、扣非净利润、加权ROE、毛利率、净利率、资产负债率、经营现金流净额
- 利润结构分析 / Profit Structure Analysis：
  - 收入构成（按业务/产品/地区）
  - 利润构成
  - 投资收益、公允价值变动等非经常性损益分析
- 杜邦分析 / DuPont Analysis：
  - ROE = 净利率 × 资产周转率 × 权益乘数
  - 各因子变化趋势及原因
- 现金流质量 / Cash Flow Quality：
  - 经营现金流/净利润比率
  - 自由现金流
  - 现金流变化原因
- 会计政策变更说明 / Accounting Policy Changes：如IFRS 17等重大变更对财务数据的影响

---

## 8. 估值分析 / Valuation Analysis

**内容：**
- 估值指标表 / Valuation Metrics：
  - PE(TTM)、PE(动态)、PB、PS、EV/EBITDA、股息率
  - 与历史估值分位对比
  - 与同业平均对比
- 同业估值对比 / Peer Valuation Comparison（对应图表3）
- 分部估值法 / SOTP Valuation（如适用）：
  - 各业务分部估值方法及结果
  - 加总后的总估值
- 三情景分档 / Three Scenarios：
  - 乐观情景（Bull Case）：假设条件、业绩预测、估值区间、目标价
  - 中性情景（Base Case）：假设条件、业绩预测、估值区间、目标价
  - 悲观情景（Bear Case）：假设条件、业绩预测、估值区间、目标价
- 估值结论 / Valuation Conclusion：当前估值水平判断、目标价区间

---

## 9. 技术分析 / Technical Analysis

**内容：**
- 起涨点判断 / Breakout Point Assessment：
  - 起涨点类型：主升型 / 反弹型
  - 起涨力度：强力型 / 普通型
  - 起涨日：日期、开盘价、收盘价、涨幅、换手率、成交量
- 均线系统 / Moving Average System：
  - 5日（攻击线）、10日（操盘线）、30日（生命线）、60日（决策线）当前值
  - 多头/空头排列状态
  - 均线金叉/死叉情况
- MACD指标 / MACD Indicator：
  - DIF、DEA当前值
  - 金叉/死叉状态
  - 红柱/绿柱状态及变化趋势
  - 0轴位置
- 量能分析 / Volume Analysis：
  - 今日成交量、昨日成交量、放大倍数
  - 5日均量、30日均量
  - 5日均量与30日均量金叉/死叉
  - 换手率分析
- 斐波那契目标位 / Fibonacci Targets（对应图表4）：
  - 基准：起涨日开盘价
  - T1(0.382)、T2(0.500)、T3(0.618)、T4(1.000)、T5(1.382)、T6(1.618)目标价
  - 止损价：开盘价-3% 或 30日线
- 综合评分 / Composite Score：
  - 技术面（/30）、基本面（/40）、资金面（/20）、市场环境（/10）
  - 总分（/100）

---

## 10. 风险管理 / Risk Management

**内容：**
- 风险矩阵 / Risk Matrix（7维度）：
  - 市场风险、行业风险、公司风险、财务风险、技术面风险、估值风险、黑天鹅风险
  - 每个风险的描述、影响程度、发生概率
- 风险画像雷达图 / Risk Radar Chart（对应图表7）
- 止损纪律 / Stop-Loss Discipline：
  - 价格止损：具体价位
  - 均线止损：具体均线
  - 时间止损：具体交易日数
  - 量能止损：具体量能条件
- 止盈策略 / Take-Profit Strategy：
  - T2减仓1/3、T3减仓1/3、T4清仓
  - 各目标位对应价格
- 证伪信号 / Falsification Signals（至少3个）：
  - 信号描述、观察方向、观察期间、数据来源入口

---

## 11. 投资建议 / Investment Recommendation

**内容：**
- 综合评分表 / Composite Score Table：
  - 技术面、基本面、资金面、市场环境各维度得分及总分
- 投资逻辑总结 / Investment Logic Summary：
  - 核心多头逻辑3条
  - 核心空头逻辑3条
- 条件式判断 / Conditional Assessment：
  - 在什么条件下看好
  - 在什么条件下看空
- 操作建议 / Operation Suggestions：
  - 如用户有持仓：持仓建议、加仓/减仓条件
  - 如用户无持仓：关注价位、介入条件
- 目标价区间 / Target Price Range：12个月目标价（区间，非单点）

---

## 12. 免责声明 / Important Disclosures

**内容（必须包含）：**
- 评级定义 / Rating Definitions（如使用评级）
- 重要信息 / Important Information
- 利益冲突披露 / Conflict of Interest Disclosure
- 免责声明 / Disclaimer：
  - 本报告仅供参考，不构成投资建议
  - 股市有风险，投资需谨慎
  - 报告基于公开信息，不保证准确性和完整性
  - 投资者应自行判断并承担投资风险

---

## 报告排版规范 / Formatting Standards

### 字体 / Fonts
- 英文：Helvetica Neue, Arial, sans-serif
- 中文：PingFang SC, Heiti SC, Hiragino Sans GB, sans-serif
- 标题字号：18-24px
- 正文字号：12-14px
- 表格字号：10-12px

### 配色 / Color Scheme
- 主色（深蓝）：#002B5C
- 辅色（金色）：#C5A572
- 强调色（浅蓝）：#60A3D9
- 正文：#333333
- 背景：#FFFFFF
- 表格表头背景：#002B5C，文字白色
- 表格隔行背景：#F5F5F5

### 页面设置 / Page Setup
- 尺寸：A4（210mm × 297mm）
- 页边距：上下20mm，左右15mm
- 页眉：Morgan Stanley | Investment Research + 股票代码
- 页脚：页码 + 免责声明提示
- 使用CSS `@page` 规则控制打印样式

### 表格规范 / Table Standards
- 所有表格必须有表头
- 数字右对齐，文字左对齐
- 百分比保留2位小数
- 金额标注单位（亿元/万元/元）
- 关键数据加粗或高亮
- 表格边框：1px solid #DDDDDD

### 图表规范 / Chart Standards
- 所有图表必须有标题（英中双语）
- 坐标轴标签清晰（英中双语）
- 图例清晰
- 数据来源标注
- 分辨率：200 DPI
- 格式：PNG
- 中文字体：PingFang SC
