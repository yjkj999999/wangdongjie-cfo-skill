# 估值框架 / Valuation Framework

## 一、估值方法概览 / Valuation Methods Overview

| 方法 | 类别 | 适用场景 | 不适用场景 |
|---|---|---|---|
| PE（市盈率） | 相对估值 | 盈利稳定的公司 | 亏损公司、周期性公司 |
| PB（市净率） | 相对估值 | 金融、地产、重资产公司 | 轻资产、高成长公司 |
| PS（市销率） | 相对估值 | 高成长、尚未盈利公司 | 利润率差异大的行业 |
| EV/EBITDA | 相对估值 | 资本结构差异大的公司 | 金融公司 |
| DCF（现金流折现） | 绝对估值 | 现金流可预测的公司 | 早期、高不确定性公司 |
| SOTP（分部估值） | 绝对估值 | 业务多元化的集团 | 单一业务公司 |
| 股息折现模型 | 绝对估值 | 高股息、稳定分红公司 | 不分红公司 |

---

## 二、相对估值法 / Relative Valuation

### 2.1 PE（市盈率）/ Price-to-Earnings Ratio

**公式：**
```
PE(TTM) = 总市值 / 最近12个月归母净利润
PE(动态) = 总市值 / 预测全年归母净利润
```

**分析要点：**
- 与历史PE分位对比（5年/10年）
- 与同业平均PE对比
- 与行业平均PE对比
- PEG = PE / 净利润增速，PEG<1可能低估

**适用行业：**
- 消费、医药、科技等盈利稳定行业
- 盈利为正且稳定增长的公司

**不适用：**
- 亏损公司（PE为负）
- 周期性公司（盈利波动大）
- 金融公司（用PB更合适）

### 2.2 PB（市净率）/ Price-to-Book Ratio

**公式：**
```
PB = 总市值 / 归属于母公司股东权益
PB = 每股股价 / 每股净资产
```

**分析要点：**
- 与历史PB分位对比
- 与同业平均PB对比
- ROE-PB关系：高ROE公司应有高PB
- PB<1可能意味着破净，但需结合ROE判断

**适用行业：**
- 银行、保险、证券等金融行业
- 地产、钢铁、煤炭等重资产行业
- 净资产占比高的公司

**不适用：**
- 互联网、软件等轻资产公司
- 高成长、高研发投入公司
- 品牌价值高但净资产低的公司

### 2.3 PS（市销率）/ Price-to-Sales Ratio

**公式：**
```
PS = 总市值 / 营业收入
PS = 每股股价 / 每股营收
```

**分析要点：**
- 与同业平均PS对比
- 结合净利率分析：高净利率公司应有高PS
- 收入增速与PS的匹配度

**适用行业：**
- 高成长、尚未盈利的科技公司
- 互联网、SaaS等公司
- 周期性行业底部（盈利为负时）

**不适用：**
- 利润率差异极大的行业横向对比
- 收入质量差的公司

### 2.4 EV/EBITDA / Enterprise Value to EBITDA

**公式：**
```
EV = 总市值 + 有息负债 - 货币资金
EBITDA = 净利润 + 所得税 + 利息费用 + 折旧 + 摊销
EV/EBITDA = EV / EBITDA
```

**分析要点：**
- 剔除资本结构差异，更适合跨公司比较
- 剔除折旧摊销政策差异
- 与同业平均对比

**适用行业：**
- 资本密集型行业
- 并购估值
- 不同资本结构的公司对比

**不适用：**
- 金融公司（资本结构是业务的一部分）
- 轻资产公司（折旧摊销少）

## 三、绝对估值法 / Absolute Valuation

### 3.1 DCF（现金流折现模型）/ Discounted Cash Flow

**基本公式：**
```
企业价值 = Σ(自由现金流t / (1+WACC)^t) + 终值 / (1+WACC)^n
股权价值 = 企业价值 - 净债务
每股价值 = 股权价值 / 总股本
```

**关键参数：**

1. **自由现金流（FCF）**
   ```
   FCFF = EBIT × (1-税率) + 折旧摊销 - 资本支出 - 营运资金增加
   FCFE = FCFF - 利息费用 × (1-税率) + 净借款增加
   ```

2. **加权平均资本成本（WACC）**
   ```
   WACC = (E/V) × Re + (D/V) × Rd × (1-税率)
   其中：
   Re = 无风险利率 + β × 市场风险溢价（CAPM）
   Rd = 债务成本
   E/V = 股权占比
   D/V = 债务占比
   ```

3. **终值（Terminal Value）**
   - 永续增长法：TV = FCFn × (1+g) / (WACC - g)
   - 退出倍数法：TV = EBITDAn × 退出倍数

**DCF敏感性分析：**
- WACC ±1% 对估值的影响
- 永续增长率 ±0.5% 对估值的影响
- 制成敏感性分析矩阵

**适用场景：**
- 现金流可预测的成熟公司
- 业务稳定、有明确增长路径的公司

**不适用：**
- 早期创业公司（现金流不可预测）
- 高不确定性行业
- 金融公司（现金流定义不同）

### 3.2 SOTP（分部估值法）/ Sum-of-the-Parts

**方法：**
1. 将公司业务拆分为多个独立分部
2. 对每个分部选择最合适的估值方法
3. 分别估值后加总
4. 扣除总部费用、净债务等
5. 得到公司整体估值

**分部估值方法选择：**
- 金融业务：PB估值
- 制造业务：PE或EV/EBITDA估值
- 科技业务：PS或PE估值
- 地产业务：NAV（净资产价值）估值

**适用场景：**
- 业务多元化的集团公司
- 各业务估值方法差异大的公司
- 存在控股折价的公司

**不适用：**
- 单一业务公司
- 业务协同效应强、难以拆分的公司

## 四、估值分档表 / Valuation Scenario Table

当关键输入未知时，使用分档表给出条件式判断，不假设也不拒答。

**模板：**

| 档位 | 触发条件（未知量取值区间） | 该档下的判断方向与优先顺序 | 该档被推翻的信号 |
|---|---|---|---|
| 乐观 | 行业增速>X%，公司市占率提升 | 看好，目标价区间A-B | 行业增速低于X%，市占率下降 |
| 中性 | 行业增速X%-Y%，市占率稳定 | 中性，目标价区间C-D | 行业增速低于Y%，业绩低于预期 |
| 悲观 | 行业增速<Y%，市占率下降 | 谨慎，目标价区间E-F | 行业增速回升，市占率提升 |

**分档表硬约束：**
- 档内不得出现绝对金额，只能出现相对量（占收入比例、倍数区间、增速区间）
- 通用默认区间必须作为分档的自变量出现在"触发条件"列
- 结尾列出"补齐哪几项后可给精确值"，最多5项

## 五、估值质量门禁 / Valuation Quality Gates

交付估值结论前必须检查：

1. **口径一致性**：比较前核对合并口径、分部边界、产品/地域范围、分母定义、reported还是adjusted、币种与单位
2. **数据来源**：估值输入数据必须有一手或库级来源标记
3. **方法适用性**：说明为什么选择该估值方法，该方法成立需要哪些前提
4. **假设透明**：所有假设（增长率、折现率、利润率等）必须明确列出
5. **敏感性分析**：关键参数变化对估值的影响
6. **不给单点**：只给估值区间和条件式框架，不给单点目标价
7. **反方观点**：列出估值可能高估或低估的理由

## 六、常见估值陷阱 / Common Valuation Pitfalls

### 6.1 周期股估值陷阱
- 周期顶部PE低，看似便宜，实际是高点
- 周期底部PE高，看似贵，实际是低点
- 应对：用PB或周期平均盈利估值

### 6.2 成长股估值陷阱
- 高增长预期已反映在高估值中
- 增速一旦放缓，估值杀跌
- 应对：关注PEG，增速与估值匹配度

### 6.3 价值陷阱
- 低PE低PB看似便宜，但基本面持续恶化
- 估值低有其合理性
- 应对：结合ROE趋势、现金流质量判断

### 6.4 会计政策变更影响
- 会计准则变更（如IFRS 17）导致财务数据不可比
- 应对：重述历史数据，统一口径后比较

### 6.5 一次性损益扭曲
- 非经常性损益（资产处置、减值、政府补贴）扭曲PE
- 应对：使用扣非净利润计算PE

## 七、估值结论输出规范 / Valuation Conclusion Output

估值结论必须包含：

1. **当前估值水平判断**：高估/合理/低估，及依据
2. **估值方法及前提**：使用了哪些方法，各方法成立的前提
3. **估值区间**：12个月目标价区间（非单点）
4. **三情景分析**：乐观/中性/悲观情景下的估值
5. **关键假设**：增长率、利润率、折现率等核心假设
6. **敏感性分析**：关键参数变化对估值的影响
7. **反方观点**：估值可能错误的理由
8. **证伪信号**：会推翻估值逻辑的可观察信号
