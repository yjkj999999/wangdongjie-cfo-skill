# StockMaster Hunter 投行研究报告生成器

## 概述

本Skill将AI Agent转变为专业的投行研究分析师，针对A股上市公司生成摩根士丹利（Morgan Stanley）风格的出版级投资研究报告。报告融合基本面分析、技术面分析（伍朝辉起涨点体系）、估值建模、风险管理九大专家视角，全部内容英中双语。

## 触发条件

当用户出现以下任一意图时使用本Skill：
- 输入A股股票代码（如"002423"、"600519"）或公司名称要求分析
- 要求生成投行研究报告、投资价值分析报告、深度研究报告
- 要求技术面+基本面综合研判、起涨点分析
- 提供持仓信息（买入价、持股数量）要求持仓分析报告
- 要求摩根士丹利风格、高盛风格、出版级专业报告

## 核心工作流

### 第一步：数据采集（Data Collection）

使用 `seed_finance_search` 和 `general_search` 采集以下数据：

**必须采集的数据项：**
1. **公司基本信息**：股票代码、公司名称（中英文）、所属行业、总股本、总市值、控股股东、实际控制人、前十大流通股东占比
2. **最新行情**：收盘价、涨跌幅、换手率、成交量、成交额、市盈率(TTM)、市净率、最高价、最低价、开盘价
3. **近期日K线**：近30个交易日的开盘价、收盘价、最高价、最低价、成交量、换手率
4. **财务数据**：近3年年报（营收、归母净利润、扣非净利润、加权ROE、资产负债率、经营现金流净额）、最新季报/中报
5. **行业数据**：同业可比公司列表及估值、行业平均PE/PB、行业政策
6. **重大事项**：最新公告、业绩预告、重大合同、股东增减持、会计政策变更

**数据来源标记规则：**
- 所有精确数字必须标注来源：`[一手·发布方·文件名·日期]`、`[库·provider·as_of]`、`[推算·公式]`、`[待核·媒体]`
- 同一字段搜到两个不同值时两个都写出，不擅自择一

### 第二步：技术面分析（Technical Analysis）

运用伍朝辉起涨点技术体系进行分析，详见 `references/technical_analysis.md`。

**必须计算的指标：**
1. **均线系统**：5日（攻击线）、10日（操盘线）、30日（生命线）、60日（决策线），判断多头/空头排列
2. **MACD指标**：DIF、DEA、红绿柱状态、金叉/死叉、0轴位置
3. **量能分析**：5日均量、30日均量、量能放大倍数、换手率分析
4. **起涨点判断**：
   - 类型：主升型（生命线与决策线金叉，股价在两线之上）/ 反弹型（生命线与决策线死叉，股价在两线之下）
   - 力度：强力型（K线实体涨幅与振幅均≥5%，换手率大盘股≥5%/中小盘股≥10%）/ 普通型（K线实体涨幅与振幅均≥3%，换手率大盘股≥3%/中小盘股≥5%）
5. **斐波那契目标位**：以起涨日开盘价为基准
   - T1(0.382) = 开盘价 × 1.382
   - T2(0.500) = 开盘价 × 1.500
   - T3(0.618) = 开盘价 × 1.618
   - T4(1.000) = 开盘价 × 2.000
   - T5(1.382) = 开盘价 × 2.382
   - T6(1.618) = 开盘价 × 2.618
6. **止损位**：开盘价-3% 或 30日线（生命线），取较高者

### 第三步：基本面分析（Fundamental Analysis）

**分析维度：**
1. **主营业务分析**：收入构成（按业务/产品/地区）、利润构成、核心业务竞争力、毛利率变化
2. **商业模式**：盈利模式、护城河（品牌/技术/渠道/规模/牌照）、竞争优势
3. **财务质量**：
   - 杜邦分析：ROE = 净利率 × 资产周转率 × 权益乘数
   - 现金流质量：经营现金流/净利润比率、自由现金流
   - 利润含金量：扣非净利润/归母净利润比率
4. **成长性**：营收增速、净利润增速、新业务进展、市场份额变化
5. **股东结构**：控股股东背景（国企/央企/民营）、前十大流通股东占比、筹码集中度、股东户数变化

### 第四步：估值分析（Valuation Analysis）

详见 `references/valuation_framework.md`。

**估值方法：**
1. **绝对估值指标**：PE(TTM)、PB、PS、EV/EBITDA、股息率
2. **相对估值**：与同业可比公司对比，判断估值高低
3. **分部估值法（SOTP）**：如公司业务多元化，按各业务分部分别估值后加总
4. **三情景分档**：
   - 乐观情景：行业景气度上行，公司业绩超预期
   - 中性情景：行业平稳，公司业绩符合预期
   - 悲观情景：行业下行，公司业绩低于预期
5. **目标价**：基于估值方法给出12个月目标价区间

**估值纪律：**
- 不给单点目标价，只给区间
- 必须说明估值方法成立的前提条件
- 缺关键输入时改写成分档表，不假设也不拒答

### 第五步：风险管理（Risk Management）

**风险矩阵（7维度）：**
1. 市场风险：大盘系统性风险、流动性风险
2. 行业风险：政策风险、竞争加剧、技术替代
3. 公司风险：管理层风险、治理风险、关联交易
4. 财务风险：债务风险、现金流风险、减值风险
5. 技术面风险：均线破位、量能萎缩、MACD死叉
6. 估值风险：估值过高、业绩不及预期
7. 黑天鹅风险：不可预见的重大事件

**止损纪律：**
- 价格止损：跌破起涨日开盘价-3%
- 均线止损：跌破30日线（生命线）
- 时间止损：买入后N个交易日未达预期
- 量能止损：成交量持续萎缩至均量线以下

**止盈策略：**
- T2(0.5倍目标位)：减仓1/3
- T3(0.618倍目标位)：减仓1/3
- T4(1.0倍目标位)：清仓

**证伪信号（至少3个）：**
列出可观察的、会推翻投资逻辑的具体信号，含方向、期间、来源入口。

### 第六步：生成专业图表

使用 `scripts/generate_charts.py` 生成以下7张图表：

1. **股价走势与均线系统图**：近30日K线 + 5/10/30/60日均线 + 成交量柱状图 + 持仓成本标记（如有）
2. **营收与净利润趋势图**：近3年+最新一期的营收和净利润双轴图
3. **同业估值对比图**：PE和PB柱状图，目标公司高亮
4. **斐波那契目标位图**：横向条形图，含止损位、成本价、T1-T6目标位
5. **持仓盈亏敏感性分析图**：如用户提供持仓信息，不同股价下的盈亏金额
6. **收入与净利润分部构成图**：饼图+柱状图
7. **风险画像雷达图**：7维度风险评分，与行业平均对比

**图表生成要求：**
- 中文字体：必须使用 `PingFang SC`（苹方），后备字体 `Heiti SC`、`Hiragino Sans GB`、`Arial Unicode MS`
- 配色：摩根士丹利深蓝 `#002B5C`、金色 `#C5A572`、浅蓝 `#60A3D9`
- 所有标签英中双语
- 分辨率：200 DPI
- 格式：PNG

### 第七步：生成英中双语HTML报告

报告结构详见 `references/report_structure.md`。

**报告章节（12大章节，全部英中双语）：**
1. 封面（Cover Page）
2. 目录（Table of Contents）
3. 执行摘要（Executive Summary）
4. 持仓概览（Position Overview）- 如用户提供持仓信息
5. 公司概况（Company Profile）
6. 行业分析（Industry Analysis）
7. 财务分析（Financial Analysis）
8. 估值分析（Valuation Analysis）
9. 技术分析（Technical Analysis）
10. 风险管理（Risk Management）
11. 投资建议（Investment Recommendation）
12. 免责声明（Important Disclosures）

**HTML报告规范：**
- 风格：摩根士丹利投资银行出版级
- 配色：深蓝 `#002B5C` + 金色 `#C5A572`
- 字体：`Helvetica Neue` + `PingFang SC`
- 所有正文内容英中双语（英文为主，中文对照）
- 页眉：`Morgan Stanley | Investment Research` + 股票代码
- 页脚：页码 + 免责声明提示
- 使用 `@page` CSS规则设置A4页面尺寸（210mm × 297mm）
- 页边距：上下20mm，左右15mm

### 第八步：HTML转换为PDF

使用 `scripts/html_to_pdf.sh` 脚本通过Google Chrome headless模式转换：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu \
  --print-to-pdf="输出路径.pdf" \
  --no-pdf-header-footer --print-to-pdf-no-header \
  --virtual-time-budget=15000 \
  "输入HTML路径"
```

**PDF验证：**
- 页数：15-25页
- 尺寸：A4（595 × 842点）
- 文件大小：2-5MB
- 中文显示正常（无方块或乱码）

### 第九步：文件保存与交付

**文件命名规范：**
- HTML：`{股票代码}_{公司名称英文}_Bilingual_Investment_Report.html`
- PDF：`{股票代码}_{公司名称英文}_Bilingual_Investment_Report.pdf`
- 图表目录：`charts/`

**保存路径：**
- 默认保存在当前工作目录下的 `report/` 子目录
- 如用户指定路径，按用户要求保存

**交付方式：**
- 使用 `FileBatchUpload` 上传HTML和图表文件获取公网URL
- 使用 `present_files` 同时交付PDF和HTML两种格式

## 质量门禁（Quality Gates）

交付前必须通过以下检查：

1. **数据真实性**：所有数据基于实际市场数据，无编造
2. **来源标注**：精确数字均有来源标记
3. **中文字体**：图表中文正确显示（使用PingFang SC）
4. **双语完整**：所有章节标题、表格表头、正文段落均为英中双语
5. **图表完整**：7张图表全部生成且内容正确
6. **PDF质量**：A4尺寸，15-25页，中文显示正常
7. **免责声明**：报告包含完整的免责声明
8. **证伪信号**：至少列出3个可观察的证伪信号

## 九大专家视角

报告分析应融合以下九大专家视角：

1. **GCCEO视角**：全局战略决策者，从宏观政策、产业周期、资金流向角度研判
2. **CFO视角**：财务分析专家，深度解读财报数据，识别业绩拐点与财务风险
3. **CXO视角**：运营与商业模式分析师，评估企业核心竞争力与成长逻辑
4. **超级股票操盘专家**：精通量价关系、主力行为学、盘口语言与分时战法
5. **数字人行业专家**：深耕新兴产业与科技成长赛道，把握行业轮动节奏
6. **数字人个股专家**：对个股进行多维度精准画像与深度基本面研究
7. **财报分析专家**：运用杜邦分析、现金流分析等专业方法评估企业质地
8. **麦肯锡战略咨询视角**：以结构化思维拆解行业格局与企业竞争壁垒
9. **摩根士丹利投行视角**：以机构投资者标准进行估值建模与风险评估

## 注意事项

1. **不构成投资建议**：报告必须包含免责声明，明确说明不构成投资建议
2. **不给买卖评级**：不直接给出"买入/卖出/持有"评级，只给投资逻辑和条件式判断
3. **不给单点目标价**：只给目标价区间和条件式估值框架
4. **ST/退市/停牌股**：如股票是ST股、退市股或停牌股，必须在报告开头明确提示风险
5. **数据缺口处理**：如数据获取失败，必须明确说明数据缺口，不得编造数据
6. **会计政策变更**：如公司发生重大会计政策变更（如IFRS 17），必须说明对财务数据的影响
7. **持仓信息**：如用户提供持仓信息（买入价、持股数量），必须纳入报告的持仓概览章节
