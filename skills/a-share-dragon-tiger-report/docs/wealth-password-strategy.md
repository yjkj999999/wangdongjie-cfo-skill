> 本文是 A股涨停板龙虎榜深度研判 + 财富密码策略包的**投资方法总纲**。
> 与代码实现一一对应：`strategy/` 下七个模块实现了本文每一节公式与闸门。
> 测试覆盖：107 个断言全绿（`python3 strategy/test_formulas.py`）。

## 1. 投资理念

以公司的基本面为核心，侧重投资具有高增长潜力的新兴产业，寻求市场价格低于企业内在价值的投资机会。

- 自上而下：先寻找低估值行业 → 再从行业寻找低估值股票 → 最后从公司基本面再次筛选精准到个股。
- 以中长期逻辑为主，中短线波段赚取差价。
- 长期跟踪新兴科技领域。

## 2. 产品特点

| 维度 | 内容 |
|---|---|
| 全方位市场分析 | 行业动态 + 公司基本面双维度 |
| 选股模式 | 低估值行业 → 低估值个股 → 基本面复核 |
| 时间节奏 | 中长期逻辑为主 + 中短线波段 |
| 数据驱动 | 月线历史分位（主判据）+ 额比（辅助），非「凭感觉」 |

## 4. 核心公式

### 4.1 综合分 S（满分 100）

```
S = 0.30·tech + 0.25·flow + 0.20·fund + 0.15·cycle + 0.10·fib
   + 加分 − 减分
```

| 子项 | 含义 | 来源 |
|---|---|---|
| tech  | 技术形态（低位 + 放量） | `funnel.py` L1/L2 |
| flow  | 资金流（龙虎榜净买、主力净流入） | `pipeline.py` score_row |
| fund  | 基本面（盈利、增速、筹码） | `filters.py` L3 |
| cycle | 产业周期位置（政策 / 景气） | playbook |
| fib   | 斐波那契位置（0.618 回撤位 100 分，向两侧线性衰减） | `formulas.py` fib_score |

### 4.2 α 预算（按市场阶段）

| 阶段 | α_max | 冰点期 |
|---|---:|---:|
| I 趋势启动 | 40% | ×0.5 |
| II 趋势延续 | 30% | ×0.5 |
| III 高位震荡 | 15% | ×0.5 |
| IV 退潮 | 5% | ×0.5 |

约束：Σ开仓名义 ≤ α_max × 权益。

### 4.3 仓位 N

```
N = floor(权益 × r ÷ (entry − stop))
```

- 冰点期 r = 0.5%
- 常态 r = 1.0%
- 单票上限 10%、单行业上限 30%（三道限额同时校验，超额拒绝）

### 4.4 熔断

| 回撤 | 动作 |
|---:|---|
| ≥ 15% | 减仓至 α 预算的 50% |
| ≥ 25% | 停机，停止一切开仓并复盘 |

### 4.5 凯利（参考，不作为主仓位来源）

```
f = min(p − (1−p)/b, 0.25) × 0.5
```

### 4.6 考核带

**年化 12% – 25%**，按年复利；看板：执行完整率 + 风控合规率。

## 5. 六条已确认口径（v2，2026-09-12 定稿，永久生效）

唯一口径源：`strategy/calibers.py`。报告首页必须写死口径版本，任何变更必须：

1. 修改 `calibers.py` 并升级 `CALIBER_VERSION`；
2. 全量重算所有历史结论；
3. 在新报告首页披露 ±N 只敏感度。

| # | 口径 | v2 取值 | v1 → v2 差异 |
|---|---|---|---|
| ① | 国企央企背景 | **偏好项**（+6 分） | v1 曾视为门槛 → 民企 0 只假警报 |
| ② | 产业偏好 | **新兴科技成长优先**（+8 分） | — |
| ③ | 净利润增长率 | **半年口径**（最新中报年内同比） | v1 用年度 → 整批结论翻转（±1 只敏感度） |
| ④ | 单年亏损 | **减分项**（−10 分） | v1 一票否决；连续两年年报亏损 = 否决 |
| ⑤ | 「链」形态主题 | **跳过 L1 否决权**（行业层仅定性） | v1 行业层硬拦 |
| ⑥ | 基础可交易性 | **L2.5 独立层**（在 L2 与 L3 之间） | v1 混在 L3 一票否决里 |

### 5.1 增速红线（量化）

- **硬线**：中报同比 ≤ 0 → 排除
- **减分项**：中报同比 > 0 但 < 上一年度增速的 50% → 重大减分 −15 分

50% 相对线是**框架自定默认值**，非市场共识。收紧为「任何减速即排除」可使过会数量再减 1 只（恒瑞医药示例）。

## 6. 四层漏斗（L1 → L2 → L2.5 → L3）

### 6.1 L1 行业

- **主判据**：历史分位（3 年月线收盘分位） ≤ 25%
- **辅助**：额比（近 3 个**已完结**月成交额均值 / 前 12 个已完结月均值） ≥ 1.0×
- **链形态主题**（口径⑤）：跳过 L1 否决权

### 6.2 L2 个股

- 与 L1 同法：分位 ≤ 25% + 额比 ≥ 1.0×
- 个股分位离散度 ≥ 60pp 报警：「方向正确 ≠ 个股正确」

### 6.3 L2.5 基础可交易性校验（口径⑥）

独立层，**不计入** L3 一票否决统计：

- 已退市 / 退市整理期 → 剔除
- ST / *ST → 剔除
- 停牌 → 剔除
- 净资产为负（PB < 0）→ 剔除
- 上市未满 60 个交易日 → 剔除
- 近 20 日均成交额 < 3000 万元 → 剔除

### 6.4 L3 基本面

| 条件 | 处理 |
|---|---|
| 连续两年年报亏损 | 一票否决 |
| 单年亏损 | 减分 −10 分，不否决 |
| 中报归母同比 ≤ 0 | 增速硬线，否决 |
| 中报同比 < 上年度的 50% | 重大减分 −15 分 |
| 控股股东为国企央企 | 加分 +6 分 |
| 属新兴科技成长 | 加分 +8 分 |
| 扣非归母为负 | 盈利质量存疑，提醒 |

| 层 | 内容 | 观察点 |

| ① 制度层 | 十五五六张网 + 六大新兴支柱 + 六大未来产业 | 政策落地节奏 |

## 8. 盘前 6 项

1. **市场阶段** —— 判定 I/II/III/IV 并确认是否冰点
2. **α 预算** —— 权益 × α_max，扣除已开仓
3. **回撤校验** —— 峰值权益 vs 现值
4. **候选复核** —— 重跑四层漏斗
5. **入场与止损** —— entry / stop / 斐波那契位
6. **公告与解禁** —— 减持、问询、业绩预告
